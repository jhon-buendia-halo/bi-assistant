- [design/wireframes/](design/wireframes/README.md): one 1440 × 960 HTML page per screen. The kit imports the app's `tokens.css` and `components.css`, so token and component changes reach the pages, and `shell.js` draws the frame, rail, banner and panel. Also an index with live thumbnails, and [flows.md](design/wireframes/flows.md) with the as-built flows per role compared with the proposed Figma board.
- The v0.29.0 baseline: User CU1–CU7 (with CU6b clarification and CU7b pending suggestions), Maker CM1–CM4 and Platform admin CA1–CA7, matched against the evidence screenshots.
- The `wireframes` skill ([.claude/skills/wireframes/SKILL.md](.claude/skills/wireframes/SKILL.md)) covers co-designing proposed pages, syncing as-built pages after a UI change, and getting them into Figma. It adds `render.mjs` (Playwright PNGs) and `build-icons.mjs` (lucide subset, resolving the old names the app imports).
- CLAUDE.md *Wireframe convention*: proposed wireframes are confirmed before the UI spec (step 5), and as-built wireframes change in the same PR as the UI (step 10). `scripts/check-specs.py` check 9 enforces page metas, folders and index coverage.
- ui.md points at the wireframes; the stale `The agent editor arrives with BA-155` copy entry is removed.
