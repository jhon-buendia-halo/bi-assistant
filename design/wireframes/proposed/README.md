# Proposed wireframes

One folder per epic, `proposed/<EPIC-ID>/`, holding the screens being co-designed for it (mode 1 of the `wireframes` skill, [.claude/skills/wireframes/SKILL.md](../../../.claude/skills/wireframes/SKILL.md)). Pages carry `<meta name="wf-status" content="proposed">` and numbered `wf-note` callouts for open decisions.

When the epic ships, its pages are folded into `as-built/` to match what was built, and the epic's folder is deleted.

No epic has proposed wireframes yet. The proposal drawn before this folder existed is the Figma board's sections 1–3; [../flows.md](../flows.md) compares it with what shipped.
