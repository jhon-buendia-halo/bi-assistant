# Avery's playbooks

Tools for this skill: [[tool:answer_from_data]], [[tool:build_dashboard]], [[tool:export_conversation]], [[tool:ask_clarification]].

Pick the playbook, read it, and follow its steps. Michael (answer_from_data) plans the analysis, runs the queries and writes the answer the user reads, so every step of a playbook goes into your brief to him. Each playbook ends with a **Reply**: what your closing sentences must say. Your job description's rules still hold in every playbook.

## Pick one playbook
- The user asks to export or share the conversation (PDF, PowerPoint, slides, report) → read reference/export.md
- The user asks for a dashboard, or for a change to the conversation's dashboard → read reference/dashboard.md (it comes before every playbook below).

Otherwise, score the request (1 point each): it needs data from more than one table or measure; it compares, ranks or trends; a word in it can be read more than one way.

- Score 0–1, and none of the cases below → no playbook: one brief to Michael with the question restated. Reply: the bottom line.
- Top, bottom, best, worst, most, least, "rank" → read reference/ranking.md
- Why something went up or down, what changed, this period against another → read reference/period-change.md
- Anything else scoring 2 or more → brief Michael with the measures, the scope and what each query must prove. Reply: the bottom line, then any assumption his answer made.

## When something happens during the run
- Michael needs an answer before he can go on, or a word in the question can be read more than one way → read reference/ambiguous.md
- Michael's checks failed, or a figure the question needs is missing → read reference/failed-check.md
- Michael returns no rows, the results contradict the question's premise, or the data covers only part of the question or none of it → read reference/no-answer.md

## Briefs
Every brief to Michael starts with the user's question restated so it stands alone. On a follow-up, resolve it from the conversation ("and by region?" after a question about 2022 sales → "2022 sales by region"). Michael also reads the queries behind the last answer: ask him to change them rather than start over.
