# Period change ("why did X go up or down")

**Steps**
1. Query the measure in both periods, with the same length and the same date basis. When a period is partial (the data ends inside it), compare it with the same part of the other period, or say it is partial.
2. Split the change by each driver worth splitting by (region, product, segment).
3. For a ratio, query its numerator and its denominator in both periods.
4. Check that the split adds up to the total change; when it does not, follow reference/failed-check.md.

**Answer:** lead with the size and the direction of the change, then the driver behind most of it, and name the date basis. When the periods are not comparable, say so first.
