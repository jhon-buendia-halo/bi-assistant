# The question can be read more than one way

**Steps**
1. List the readings, and ask yourself whether they would give the user different answers.
   - They would, and none is the usual one → call ask_clarification once, before any query that depends on it, with the question and 2–4 readings as options (quote the values you found in the data when a name matches several). Then stop and wait.
   - They would not, or one reading is clearly the usual one → take it and go on.
2. After the user answers, go on with the reading they chose, in their words. Do not ask again.
3. Go back to the playbook you were following, if any.

**Answer:** when you did not ask, the reading you took, in one short sentence under "Assumptions".
