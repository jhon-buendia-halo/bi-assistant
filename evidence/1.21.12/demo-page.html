Scope

  • a Visuals card third on the Context page
  • a visual_charts collection seeded once per data dir with a default catalog of 30 chart types in 9 categories (Comparison, Change over time, Part-to-whole, Distribution, Relationship, Ranking, Flow, Spatial, Numbers and tables)
  • each chart has a name, category, sample preview thumbnail, description, when to use, when to avoid, the data it needs, the renderer form the app draws it with (or none) and an enabled flag
  • the library lists charts grouped by category with search and category filters, disabled charts faded
  • add, edit (in place, where the card was), disable and delete charts
  • GET/POST /visuals, PATCH/DELETE /visuals/:id. New capability spec visuals-library
  • app-shell R3a
  • api.md, data-model.md, ui.md.

Out of scope: agents or the visual designer using the library (a later story); drawing new chart types; importing charts; per-chart sample data.

Acceptance

  • a new data dir shows the Visuals card and the 30 default charts in 9 categories with previews
  • search and a category filter narrow the list
  • a chart can be added, edited, disabled and deleted and survives a restart
  • a deleted default stays deleted
  • a duplicate or blank name is refused
  • unit tests and the build green.
